# Proof Systems Website Visual Assets

## Positioning

Use recreated, anonymised workflow visuals as the default. Real screenshots should only be used after a separate approval pass confirms they contain no client, staff, project, financial, credential or commercially sensitive data.

## Brand and type

Canonical logo, icon and favicon files live in `assets/brand/` and were copied from `50_assets/proof-systems/brand/current/`. Inter Variable 4.1 is self-hosted in `assets/fonts/` under the SIL Open Font License 1.1. No remote font or CDN is used.

## Current Safe Placeholders

The homepage uses an SVG workflow diagram plus poster-first synthetic film teasers. It does not use live screenshots.

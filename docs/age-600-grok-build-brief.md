# AGE-600 Grok Build brief

## Outcome

Implement the approved Proof Systems website repositioning from
`docs/age-600-attended-design-review.md` as a complete local static website.

Primary intended user: an owner or senior operator in an SME who knows an
important workflow is fragile, manual or difficult to control.

Smallest useful change: replace the expired founding-cohort proposition with
one coherent credibility-led journey, integrate the complete synthetic demo
portfolio, and reuse the existing safe enquiry route in a shorter form.

Simple Gate: PASS

## Owned paths

Own the complete website repository except Git metadata. Preserve the reviewed
media and privacy foundations where they remain correct. Do not modify files
outside the isolated worktree.

2. Keep the site dependency-light and statically hostable. Shared CSS and
   JavaScript assets are preferred over duplicating large inline blocks.
3. Build the eight-chapter homepage, Work index, eight individual story pages,
   short enquiry page and updated privacy/operating documentation.
4. Use clean, stable URLs for Work and stories. Preserve current public legacy
   routes through local redirect pages or static-host-compatible redirects.

   WebGL, a framework dependency, scroll hijacking, cursor replacement or an

   download or autoplay all full films eagerly. Full story films are

## Completion predicate

The predicate is true only when the complete local static site implements the
approved design and copy; all eight story routes and eight media sets are
present and internally linked; the form and privacy/operating contracts match;
responsive, keyboard, reduced-motion, no-JavaScript, media and content-safety
checks pass; the branch is clean with one or more genuine commits; and the
machine-readable completion receipt states all known limitations.

## Proof

At minimum provide and run:

- repository-specific content, route, form, privacy and media checks;
- `git diff --check`;
- Python compile checks for any Python test tooling;
- an HTTP crawl of every public route with asset/link verification;
- media probes for codec, dimensions, duration, poster and VTT validity;
- responsive UAT instructions for 1440×900, 1280×720, 768×1024 and 390×844;
- keyboard, focus, reduced-motion and no-JavaScript checks;
- a production-like performance check proving poster-first/lazy media loading.

Do not claim browser UAT that was not actually performed. Leave exact local
review commands and server instructions for independent Codex review.

## Permission boundary

Approved: modify and test the isolated local website worktree; generate local
posters, VTT files and test artefacts; make local commits; use the staged
synthetic media only.

Not approved: push, merge, preview-host, deploy, publish, submit the form to
production, contact Pete Mills or Pantera, send the testimonial, add client
data, change Netlify/DNS/credentials/billing, or make any customer-facing
change.

## Escape hatch

If a required fact cannot be derived safely, if a source film appears to expose
non-synthetic or sensitive information, if the static architecture cannot meet
the agreed accessibility/performance contract, or if the build cannot verify a
real artefact, stop with the precise evidence and missing decision. Do not
weaken the completion predicate, invent copy, omit a required system silently
or expand authority.

## Decision log

This is a long, multi-phase lane. Maintain
`docs/age-600-build-decisions.md` as a concise append-only log for material
implementation choices. Do not record routine edits.

# Retained withdrawn Management Accounts film

The Management Accounts demonstration film is no longer a public website asset.
This directory keeps the final public rendition, poster and English captions as
they stood when withdrawn. They are not part of the deploy-ready tree built by
`tools/prepare_publish.py`.

The original AGE-600 master remains at `source/management-accounts-demo.mp4`.
`render_narrative.py` stays editable and writes this slug here, not under
`assets/demo-media/`.

Do not copy these files into `assets/` or a publish package.
